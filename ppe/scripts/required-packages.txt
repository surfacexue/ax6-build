# AX6 PPE-NSS 必装包清单（唯一真源）
#
# 为什么要有这个文件：同一份清单在两个时机用，语义不同，不能只留一份。
#   前置「校验核心功能包（缺失即中止）」：查 CONFIG_PACKAGE_<name>=y —— 证明包被「选中」，失败代价 1–2 分钟
#   后置「校验并归集产物」           ：查 <target>.manifest —— 证明包「真进了镜像」
# 两处都读本文件，加包只改这里一处；两份硬编码清单迟早漂移，那比没有校验更坏。
#
# 格式：`包名<TAB>hard|soft<TAB>说明`。空行与 # 开头为注释。
#   级别只对后置生效（前置全数中止，因为此时还没编译，早失败零浪费）：
#   hard = 缺了这轮固件不能组网 / 不能管理 / 不能远程救回 → ::error:: + exit 1，产物不落地
#   soft = 缺了只是少一个界面、语言包、可选功能或现场工具 → ::warning::，照常上传，缺失写进 out/MISSING-SOFT.txt
# 注意 1：manifest 行是 `<name> - <version>`，不是裸包名，必须按行首匹配。
# 注意 2：带 ABI 的库在 manifest 里带数字后缀（实测 libwebsockets-full -> libwebsockets-full23），
#         后置按「包名 + 纯数字后缀」容错；而 .config 里的 CONFIG_PACKAGE_ 名字不带后缀。
# 注意 3（未验证分支）：上面的「包名 + 纯数字后缀」容错至今没有在真产物上触发过——
#         run 46128616885 的 manifest 里 libwebsockets-full 是裸名 4.3.3-r1，走的是精确匹配。
#         这条分支要等真出现带 ABI 后缀的 manifest 才算验证过；在那之前别当成已验证。
#
# 机器读的两行（改清单必须同步改第一行，否则 CI 直接失败）：
#expect=35
#forbid=libwebsockets-openssl,dnsmasq,dnsmasq-dhcpv6,sing-box
